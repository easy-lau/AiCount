# AICount 0.2.0 MVP 实现计划

**生成日期**: 2026-05-18
**目标版本**: 0.2.0
**当前版本**: 0.1.2

---

## Requirements Summary

在 AICount（Tauri v2 + React 桌面应用）上新增 5 个高价值实用功能，构成 0.2.0 MVP：

1. **实时监听 session 目录** — 自动感知 Claude/Codex 新会话并刷新统计
2. **系统托盘 + 今日计数** — 托盘 tooltip 显示今日 AI 行数，点击切换窗口可见性
3. **语言/扩展名分布** — 按文件后缀聚合，donut chart + 表格
4. **活动热力图** — GitHub 风格年度日历热力图
5. **CSV/JSON 导出** — 当前筛选范围一键导出

---

## Acceptance Criteria

### 1. 实时监听
- [ ] `~/.claude/projects/**/*.jsonl` 文件新建/修改后，前端 Overview 在 ≤2s 内自动刷新
- [ ] `~/.codex/sessions/**/*.jsonl` 同上
- [ ] 监听器使用防抖（debounce 500ms），单次连续修改只触发一次刷新
- [ ] 文件变化时 `CACHE`（`src-tauri/src/code_stats/mod.rs:120`）中对应 entry 失效或被新 mtime 覆盖
- [ ] 应用启动时自动开启 watcher，关闭时正确清理（无僵尸线程）

### 2. 系统托盘
- [ ] macOS / Windows 任务栏区有 AICount 图标
- [ ] 图标 tooltip 显示 `AICount · 今日 +<N> 行`（N = 今天 0:00 起 AI 生成的 added LOC）
- [ ] 左键点击托盘 → 主窗口显示且置前；窗口已显示时 → 隐藏
- [ ] 托盘右键菜单含 `Show / Quit` 两项
- [ ] 实时监听触发后，tooltip 在 ≤3s 内更新（复用 watcher 事件）

### 3. 语言分布
- [ ] `Overview` 类型新增 `by_language: Vec<LanguageBreakdown>` 字段
- [ ] `LanguageBreakdown { language: String, extension: String, loc: u64, file_count: u32, percent: f64 }`
- [ ] 扩展名 → 语言名映射至少覆盖 [src-tauri/src/code_stats/project_loc.rs:9-15](src-tauri/src/code_stats/project_loc.rs#L9-L15) 的全部 47 个 `SOURCE_EXTENSIONS`（如 `.ts/.tsx → TypeScript`、`.rs → Rust`）
- [ ] 未识别扩展名归入 `Other`
- [ ] 前端在 [src/components/overview/OverviewPage.tsx](src/components/overview/OverviewPage.tsx) 新增一个 Card 区块：donut chart（Recharts `PieChart`）+ 表格列出 Top 10 语言
- [ ] 切换 date range / project 时，语言分布跟随刷新

### 4. 活动热力图
- [ ] 新增 Tauri 命令 `compute_heatmap(project?: string) -> HeatmapData`
- [ ] `HeatmapData { from_ms: i64, to_ms: i64, cells: Vec<HeatmapCell> }`，`HeatmapCell { date: String /* YYYY-MM-DD */, loc: u64 }`
- [ ] 默认返回过去 365 天数据
- [ ] 前端组件 `ActivityHeatmap.tsx` 以 53 周 × 7 天网格渲染（自绘 SVG，不引入新库）
- [ ] 单元格 hover 显示 `<date>: +<N> 行` tooltip
- [ ] 5 档色阶（0、1-100、101-500、501-2000、>2000），深色主题适配

### 5. CSV / JSON 导出
- [ ] 新增 Tauri 命令 `export_overview(query: OverviewQuery, format: "csv"|"json") -> String`（返回序列化后的内容）
- [ ] CSV 输出三个 section：`-- Summary --` / `-- Daily --` / `-- By Language --`，UTF-8 with BOM 兼容 Excel
- [ ] JSON 输出完整 `Overview`（含 `by_language` 与现有所有字段）
- [ ] Overview 页右上角增加 `Export` 按钮，触发 `tauri-plugin-dialog` 的 `save` 对话框（文件名默认 `aicount-YYYY-MM-DD.csv`）
- [ ] 用户选定路径后写入文件，写入失败显示 toast 错误

### 全局
- [ ] `cargo build --release` 通过，无新增 clippy warnings
- [ ] `pnpm build` 通过，TypeScript 无 error
- [ ] `src-tauri/Cargo.toml` version 升级到 `0.2.0`，`package.json` 同步
- [ ] CI（`.github/workflows/*`）构建仍通过

## Risks and Mitigations

| 风险 | 影响 | 缓解 |
|------|------|------|
| `notify` macOS FSEvents 偶发漏报 | 实时性受损 | 加入 1min 轮询兜底（`setInterval` 触发一次 reload） |
| `notify-debouncer-mini` 在大量并发写时仍连发事件 | UI 抖动 | 前端再加一层 200ms 节流（lodash-style） |
| Tauri tray-icon 在 Linux 部分发行版需 libayatana-appindicator | 跨平台 | 0.2.0 仅承诺 macOS/Windows，README 注明 |
| 365 天 heatmap 计算慢（大量 session） | 首屏卡顿 | 与 Overview 并行 invoke；后端复用现有 cache |
| CSV BOM 在 Linux 终端显示残留 | 体验差 | format 增加 `csv` / `csv-bom` 二选一；MVP 仅给一个 csv，默认带 BOM（Excel 优先） |
| 用户没有 Claude/Codex 目录 | watcher panic | spawn_session_watcher 在目录不存在时 `log::warn!` 跳过，不阻塞应用启动 |
| tray 在 dev 模式偶发不显示 | 开发体验 | 启动时检查 `app.tray_by_id` 是否成功，失败 fallback 重试一次 |
